# 多模态与感知高频面试题

本文件面向多模态大模型、视觉感知、自动驾驶/机器人感知、视觉 Agent 相关岗位。重点不是背论文名，而是能把视觉任务、模态融合、数据闭环、评估指标和工程部署讲清楚。

资料核验日期：2026-08-12。多模态模型、视觉 foundation model 和感知 benchmark 更新很快，涉及具体模型排名、API、数据集版本和 SOTA 时，请以官方页面为准。

## 准备重点

多模态与感知方向的面试通常分成 6 类：

- 基础视觉能力：分类、检测、分割、跟踪、姿态、深度、3D 检测。
- 表征学习：CNN、ViT、自监督、对比学习、视觉 foundation model。
- 多模态模型：image-text alignment、VLM 架构、visual grounding、OCR、图表/文档理解、视频理解。
- 感知工程：数据采集、标注、长尾、域迁移、传感器融合、实时部署。
- 评估指标：mAP、IoU、mIoU、Recall、HOTA/MOTA、EPE、3D AP、grounding accuracy、VQA accuracy。
- 系统设计：视觉问答系统、视觉搜索、文档理解、自动驾驶感知、机器人视觉、视觉 Agent。

## 一、基础概念与任务边界

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M001 | 多模态模型和传统计算机视觉模型有什么区别？ | 传统 CV 多面向固定任务和固定标签；多模态模型强调图文/音视频/动作等模态对齐、开放词表、指令跟随和泛化。 |
| M002 | 感知系统和多模态理解系统有什么区别？ | 感知偏检测、定位、跟踪、几何和实时性；多模态理解偏语义、推理、语言交互和知识整合。 |
| M003 | VLM、MLLM、Vision Agent 分别是什么？ | VLM 偏视觉语言模型；MLLM 是多模态大语言模型；Vision Agent 在视觉理解基础上还能规划和执行动作。 |
| M004 | 什么任务适合用 VLM，什么任务仍适合传统 CV pipeline？ | 开放语义、图文推理、文档问答适合 VLM；强实时、高精度、固定类别检测常用专用 CV 模型。 |
| M005 | image-level、region-level、pixel-level、video-level 理解有什么区别？ | 分别对应整图语义、区域定位、像素级掩码和跨帧时序理解。 |
| M006 | 开放词表识别和闭集分类有什么区别？ | 闭集分类只识别训练标签；开放词表依赖语言对齐识别未显式训练类别，但边界和评估更难。 |
| M007 | visual grounding 是什么？ | 把语言描述映射到图像区域、框、点或 mask，是 VLM 从“会说”走向“能定位”的关键。 |
| M008 | perception 和 reasoning 哪个更难？ | 二者难点不同；感知要求准确定位和鲁棒性，推理要求跨证据、多步逻辑和常识，真实系统通常二者耦合。 |

## 二、视觉基础模型与表征学习

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M009 | CNN 和 ViT 的核心差异是什么？ | CNN 有局部卷积归纳偏置；ViT 把图像切成 patch 做全局 attention，更依赖数据规模和预训练。 |
| M010 | 为什么 ViT 需要位置编码？ | patch token 本身不含空间顺序，位置编码提供空间位置信息。 |
| M011 | patch size 会影响什么？ | 小 patch 保留细节但计算更大；大 patch 更快但可能损失小目标和局部纹理。 |
| M012 | 自监督视觉学习解决什么问题？ | 减少对人工标签依赖，学习可迁移视觉特征，适合下游检测、分割、深度等任务。 |
| M013 | DINO/DINOv2 的核心思想是什么？ | 用自监督和蒸馏学习通用视觉特征，冻结特征也能迁移到多种图像和像素级任务。 |
| M014 | CLIP 为什么重要？ | 用图文对比学习把图片和自然语言放到同一语义空间，带来 zero-shot 分类和开放词表迁移能力。 |
| M015 | contrastive learning 的正负样本怎么构造？ | 匹配图文或增强视图作为正样本，batch 内其他样本作为负样本；关键是数据质量和负样本难度。 |
| M016 | 对比学习和生成式预训练有什么区别？ | 对比学习强调表示对齐和区分；生成式预训练强调恢复、预测或生成内容。 |
| M017 | 为什么视觉 backbone 通常先预训练再微调？ | 大规模预训练学通用特征，下游微调适配任务，能减少标注成本并提升泛化。 |
| M018 | 视觉 foundation model 的局限是什么？ | 可能缺精细几何、长尾类别、专业域知识、精确计数和可解释性，部署成本也更高。 |

## 三、图文多模态模型架构

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M019 | 典型 VLM 由哪些模块组成？ | 视觉编码器、投影层或 adapter、LLM、tokenizer、融合机制和输出头。 |
| M020 | 为什么需要 visual projector？ | 把视觉特征映射到 LLM 可接收的 embedding 空间，缩小视觉编码器和语言模型之间的模态 gap。 |
| M021 | early fusion、late fusion、cross-attention fusion 有什么区别？ | early 早期拼接模态，late 后期合并决策，cross-attention 在特征层交互，表达强但计算更大。 |
| M022 | BLIP-2 的 Q-Former 解决什么问题？ | 用轻量查询 Transformer 从冻结视觉编码器中抽取少量视觉 token，再连接冻结 LLM，降低训练成本。 |
| M023 | Flamingo 类模型的 gated cross-attention 思路是什么？ | 在语言模型中插入跨模态 attention，让文本 token 按需读取视觉上下文，同时尽量保留原 LLM 能力。 |
| M024 | LLaVA 类模型常见训练流程是什么？ | 先做图文对齐预训练，再用视觉指令数据做 instruction tuning。 |
| M025 | VLM 为什么会产生视觉幻觉？ | 视觉证据弱、语言先验强、训练数据偏差、OCR 错误、grounding 不准或问题本身含误导。 |
| M026 | 如何减少 VLM 视觉幻觉？ | 引用视觉证据、局部 crop 检查、检测/分割工具辅助、拒答策略、视觉一致性评测和不确定性提示。 |
| M027 | 图像 token 太多时如何处理？ | 降采样、patch pooling、query token 压缩、区域裁剪、多分辨率编码、按任务动态选帧或选区。 |
| M028 | 多图输入和单图输入的难点有什么不同？ | 多图需要跨图对应、顺序、记忆、去重、引用和长上下文管理。 |
| M029 | OCR 能力为什么对 VLM 很关键？ | 很多真实图像包含文本，文档、表格、界面、票据、图表理解都依赖文字识别和布局关系。 |
| M030 | 图表理解比普通 VQA 难在哪里？ | 需要识别坐标轴、图例、单位、趋势、数值和视觉元素之间的结构关系。 |

## 四、训练、微调与数据

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M031 | 多模态预训练常见数据有哪些？ | image-caption、interleaved image-text、OCR 文档、视频字幕、instruction data、region-caption、检测/分割标注。 |
| M032 | 图文数据噪声会带来什么问题？ | 错配、偏见、短文本弱监督、重复样本和低质量 caption 会降低对齐质量并放大幻觉。 |
| M033 | 如何清洗大规模图文数据？ | 去重、NSFW/隐私过滤、语言检测、图文相似度过滤、OCR 质量过滤、caption 长度和实体一致性检查。 |
| M034 | instruction tuning 对 VLM 有什么作用？ | 让模型从图文表征转向按人类指令回答、解释、比较、定位和拒答。 |
| M035 | LoRA/QLoRA 在多模态微调中常调哪些部分？ | 可调 projector、LLM 部分层、cross-attention 或视觉 encoder 后几层，取决于算力和任务。 |
| M036 | 冻结视觉 encoder 有什么优缺点？ | 训练便宜且稳定，但专业域和细粒度任务可能适配不足。 |
| M037 | 什么时候需要端到端微调视觉 encoder？ | 专业域差异大、细粒度视觉证据关键、检测/分割能力不足或视觉特征明显不适配时。 |
| M038 | 多模态训练如何防止语言模型遗忘？ | 小学习率、冻结部分 LLM、混合纯文本数据、adapter 训练和阶段式训练。 |
| M039 | 长尾类别问题怎么处理？ | 重采样、难例挖掘、合成数据、开放词表、主动学习和指标按频次分桶。 |
| M040 | 标注成本高时如何做数据闭环？ | 主动学习、模型辅助标注、弱监督、伪标签、人工复核和线上失败样例回流。 |

## 五、检测、分割与 Grounding

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M041 | object detection 输出什么？ | 类别、置信度和边界框，常见指标是 AP/mAP 和 IoU。 |
| M042 | two-stage detector 和 one-stage detector 有什么区别？ | two-stage 先生成候选区域再分类回归，精度强；one-stage 直接预测，速度快。 |
| M043 | anchor-based 和 anchor-free 检测有什么区别？ | anchor-based 依赖预设框；anchor-free 直接预测中心点或框参数，减少手工先验。 |
| M044 | NMS 的作用和问题是什么？ | 去除重复框；但拥挤场景和小目标可能误删，soft-NMS 或学习式去重可缓解。 |
| M045 | DETR 为什么有代表性？ | 把检测看成集合预测，用 Transformer 和 bipartite matching 避免传统 anchor/NMS 依赖。 |
| M046 | 小目标检测为什么难？ | 分辨率低、特征弱、易被下采样丢失、标注噪声影响更大。 |
| M047 | semantic segmentation、instance segmentation、panoptic segmentation 有什么区别？ | 语义分割分每个像素类别，实例分割区分对象实例，全景分割统一 stuff 和 thing。 |
| M048 | SAM 的 promptable segmentation 思路是什么？ | 图像 encoder 预计算 embedding，prompt encoder 接收点/框/mask/text 等提示，mask decoder 输出分割。 |
| M049 | SAM2 相比 SAM 的关键扩展是什么？ | 从图像扩展到图像和视频，加入 streaming memory 支持视频中的对象持续分割。 |
| M050 | open-vocabulary detection 如何实现？ | 通过图文对齐、文本 embedding、region-text matching 或语言引导 query，让检测器识别开放类别。 |
| M051 | Grounding DINO 解决什么问题？ | 用语言引导检测任意文本描述对象，支持开放词表检测和 referring expression grounding。 |
| M052 | Grounded-SAM 这类组合系统的价值是什么？ | 检测模型负责按文本找目标，SAM 负责生成精细 mask，组合实现开放词表实例分割。 |

## 六、视频理解与时序感知

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M053 | 视频理解和图像理解最大的区别是什么？ | 视频需要建模时间、运动、事件顺序、长程依赖和跨帧一致性。 |
| M054 | 视频模型如何选择帧？ | 均匀采样、关键帧采样、事件驱动采样、镜头切分、基于问题的自适应采样。 |
| M055 | 长视频理解为什么难？ | 帧数多、token 成本高、关键信息稀疏、时序依赖长、字幕/音频/画面需要对齐。 |
| M056 | optical flow 解决什么问题？ | 估计像素级运动，用于动作识别、跟踪、视频插帧、运动分割和自监督学习。 |
| M057 | tracking-by-detection 的基本流程是什么？ | 每帧检测对象，再用外观、位置、运动模型和匈牙利匹配关联轨迹。 |
| M058 | MOTA、IDF1、HOTA 分别关注什么？ | MOTA 综合误检漏检和 ID switch，IDF1 关注身份保持，HOTA 同时衡量检测和关联。 |
| M059 | 视频 VLM 如何处理音频和字幕？ | 将视频帧、字幕和音频特征对齐到时间轴，再做跨模态融合和问答推理。 |
| M060 | 如何评估视频多模态模型？ | 按短/中/长视频、字幕/无字幕、时间定位、跨片段推理、事件顺序和幻觉率分层评估。 |

## 七、3D 感知、传感器融合与自动驾驶

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M061 | 2D 检测和 3D 检测有什么区别？ | 2D 输出图像框；3D 输出空间位置、尺寸、朝向和类别，受坐标系和传感器标定影响。 |
| M062 | camera、LiDAR、radar 各有什么优缺点？ | camera 语义丰富但受光照影响；LiDAR 几何精确但成本高；radar 速度和恶劣天气强但分辨率低。 |
| M063 | 传感器融合常见层级有哪些？ | early fusion 原始数据融合，middle fusion 特征融合，late fusion 决策融合。 |
| M064 | 相机和 LiDAR 标定为什么重要？ | 外参和时间同步错误会导致投影错位，影响 2D/3D 对齐、融合和评估。 |
| M065 | BEV 表示为什么在自动驾驶感知中常见？ | BEV 统一多相机和 LiDAR 到鸟瞰空间，适合检测、地图、占用和规划接口。 |
| M066 | Occupancy Network 解决什么问题？ | 预测空间中每个体素或网格是否被占用，适合表示未知类别、可行驶空间和动态障碍物。 |
| M067 | 点云处理有哪些常见方法？ | PointNet/PointNet++、voxelization、pillar、range view、sparse convolution、point-voxel hybrid。 |
| M068 | 3D 检测常见指标有哪些？ | 3D AP、BEV AP、中心距离误差、尺度误差、朝向误差、速度误差和 nuScenes NDS。 |
| M069 | 自动驾驶感知中的 long-tail 问题是什么？ | 罕见物体、罕见天气、施工、事故、异常行为和边缘场景样本少但风险高。 |
| M070 | 感知误差如何影响规划？ | 漏检导致碰撞风险，误检导致急刹，定位/速度误差影响轨迹预测和决策。 |
| M071 | 机器人视觉和自动驾驶感知有什么不同？ | 机器人更关注近距离操作、手眼标定、物体姿态、可抓取性和闭环控制。 |
| M072 | SLAM 和感知检测是什么关系？ | SLAM 估计自身位姿和地图，检测识别语义对象，二者可结合成语义地图和可交互世界模型。 |

## 八、文档、界面与视觉 Agent 感知

| M074 | 表格识别有哪些难点？ | 单元格合并、隐形边框、多级表头、跨页、旋转扫描和数值单位。 |

| M078 | 多模态 RAG 和普通文本 RAG 有什么区别？ | 需要处理图片、表格、图表、版式、截图和跨模态引用，检索粒度更复杂。 |
| M079 | 视觉搜索系统怎么做？ | 用图像 embedding 或图文 embedding 建索引，支持以图搜图、文本搜图、属性过滤和 rerank。 |

## 九、评估指标与 Benchmark

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M081 | IoU 是什么？ | 预测区域和真实区域交并比，用于检测和分割匹配。 |
| M082 | mAP 怎么理解？ | 不同类别和阈值下 AP 的平均，反映 precision-recall 曲线整体质量。 |
| M083 | AP50 和 AP75 有什么区别？ | AP50 阈值宽松，AP75 更强调定位精度。 |
| M084 | 分割任务常用什么指标？ | mIoU、Dice/F1、mask AP、boundary F-score，按任务选择。 |
| M085 | 分类任务为什么不能只看 accuracy？ | 类别不平衡时会误导，需要 precision、recall、F1、AUC、per-class metric。 |
| M086 | VQA 或 MLLM 评估有什么问题？ | 答案形式多样、语言偏差、数据泄漏、视觉幻觉和 judge 不稳定。 |
| M087 | MMMU 主要评估什么？ | 跨学科、多图形类型、专家级感知、知识和推理能力。 |
| M088 | Video-MME 主要评估什么？ | 短到长视频、多领域、字幕/音频辅助和长时序视频理解能力。 |
| M089 | 自动驾驶数据集评估为什么要看场景分桶？ | 总体指标可能掩盖夜晚、雨天、小目标、遮挡、远距离和施工场景的问题。 |
| M090 | 线上感知系统该如何监控？ | 分布漂移、低置信度、人工接管、误检漏检、延迟、资源、场景覆盖和用户反馈。 |

## 十、部署、优化、鲁棒性与安全

| 编号 | 面试题 | 回答抓手 |
| --- | --- | --- |
| M091 | 视觉模型部署常见瓶颈是什么？ | 输入分辨率、backbone 计算、attention token 数、后处理、显存、数据拷贝和批处理策略。 |
| M092 | 如何优化视觉模型推理速度？ | 模型裁剪、蒸馏、量化、TensorRT/ONNX、降分辨率、多尺度控制、异步 pipeline。 |
| M093 | 多模态系统如何做模型路由？ | OCR/检测用专用模型，开放问答用 VLM，难题升级更强模型，低风险任务用轻量模型。 |

## 高频追问模板

回答多模态和感知题时，面试官很常追这几类：

- 你如何证明模型真的看到了图像证据，而不是靠语言先验猜？
- 指标提升 1 个点是否有业务意义？
- 模型在小目标、遮挡、夜晚、长尾类别上表现如何？
- 失败样例如何回流到数据、训练和 eval？
- 为什么选择通用 VLM，而不是专用检测/分割/OCR 模型？
- 如何在速度、精度、成本和可解释性之间权衡？
- 线上发现分布漂移后，如何定位是数据、模型、阈值还是业务变化？
- 如果视觉模型输出会触发真实世界动作，哪些环节必须加安全兜底？

## 口述答案结构

```text
1. 先定义任务和输入输出
2. 说明模型或算法核心机制
3. 讲清指标和评估集
4. 说出常见失败模式
5. 给出工程补救手段
6. 用一个项目或业务场景收尾
```
