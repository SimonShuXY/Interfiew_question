# Agent 从入门到精通手册

欢迎来到 Agent 学习手册。本手册按连续章节组织：

1. 先理解 Agent 与普通 LLM 应用的边界。
2. 再学习 LLM、提示词、上下文、工具、RAG 和记忆。
3. 然后进入 Agent 循环、规划、工作流、多 Agent 和协议。
4. 最后掌握评测、观测、安全、生产化和框架选型。

建议从 [如何使用本手册](00-how-to-use.md) 开始。

如果你正在准备面试，可以直接进入 [Agent 面试准备总览](interview-prep/00-overview.md)。该模块包含 40 天学习计划、92 道题库、系统设计题、项目与简历表达和模拟面试模板。
