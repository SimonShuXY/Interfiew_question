参考资料¶

资料核验日期：2026-08-12。以下链接优先选择官方文档和论文。框架 API、模型名和协议版本会变化，实践时请再次核对。

官方指南与工程实践¶

  • OpenAI, A practical guide to building agents：Agent 定义、适用场景、工具、指令、编排和护栏。
  • Anthropic, Building effective agents：工作流与 Agent 的区别，prompt chaining、routing、parallelization、orchestrator-workers、evaluator-optimizer 等模式。

Agent SDK 与框架¶

  • OpenAI, Agents SDK documentation：Agent、工具、handoff、guardrails、sessions、tracing。
  • LangChain, Agents documentation：create_agent、工具、上下文、流式和 LangGraph runtime。
  • LangChain, LangGraph v1 release notes：图执行、持久化、checkpoint、人机协作。
  • LlamaIndex, Agents use case documentation：Agentic RAG、工具、工作流和数据增强 Agent。
  • Microsoft, Agent Framework overview：Agents、Harness、Workflows、MCP、多 provider 和企业工程能力。
  • Microsoft, Agent Harness：Harness 作为运行时脚手架，负责工具调用、上下文、审批、观测和长任务进度。
  • Microsoft, Agent Framework Workflows：函数式工作流、图工作流、checkpoint、人机协作和多 Agent 编排。

协议¶

  • Model Context Protocol, latest specification：MCP 规范、tools、resources、prompts、authorization、安全原则和扩展。
  • Model Context Protocol, architecture overview：Host、Client、Server、数据层和传输层。
  • A2A Protocol, latest specification：Agent Card、Message、Task、Artifact、版本协商和协议绑定。
  • A2A Protocol, Life of a Task：任务生命周期、上下文 ID、任务 ID、artifact 更新。

经典论文与思想来源¶

  • Yao et al., ReAct: Synergizing Reasoning and Acting in Language Models：推理和行动交替的 Agent 思想。
  • Schick et al., Toolformer: Language Models Can Teach Themselves to Use Tools：模型学习工具使用的早期代表工作。
  • Shinn et al., Reflexion: Language Agents with Verbal Reinforcement Learning：通过语言反思和情景记忆改进 Agent 后续尝试。

多模态与感知¶

  • OpenAI, CLIP: Connecting text and images：图文对比学习、自然语言监督和 zero-shot 视觉分类。
  • Meta AI, DINOv2：自监督视觉特征、ViT backbone 和跨任务迁移。
  • Meta AI, Segment Anything：promptable segmentation、SAM 和 SA-1B 数据集。
  • Meta AI, SAM 2：图像和视频中的 promptable segmentation、streaming memory。
  • MMMU Team, MMMU benchmark：跨学科、多图形类型、专家级多模态理解与推理评测。
  • Video-MME Team, Video-MME：长短视频、多领域、字幕和音频辅助的视频理解评测。
  • Waymo, Open Dataset Perception：自动驾驶感知数据、2D/3D 标注、跟踪、分割和传感器数据。
  • nuScenes, nuScenes dataset：自动驾驶多传感器数据集，覆盖 camera、LiDAR、radar、IMU、GPS 和 3D 标注。

评测与观测¶

  • LangSmith, Evaluation concepts：离线评测、线上评测、runs、threads、human/code/LLM-as-judge/pairwise evaluator。
  • LangChain, Agent trajectory evaluations：按工具调用序列和轨迹质量评测 Agent 行为。
  • OpenAI, Evals：面向模型和 Agent 能力的评测研究与数据集。

推理、训练与长上下文优化¶

  • DSPy, Optimizers documentation：用指标优化 LLM 程序的 prompt、few-shot 示例或模型权重。
  • DeepSpeed, ZeRO documentation：通过分片优化器状态、梯度和参数降低大模型训练显存冗余。
  • Madaan et al., Self-Refine：通过生成、反馈、改写循环在推理时改进输出。
  • Shazeer, Fast Transformer Decoding: One Write-Head is All You Need：Multi-Query Attention 通过共享 key/value 降低解码时 KV cache 和内存带宽压力。
  • Dao et al., FlashAttention：IO-aware exact attention，通过分块计算减少高带宽显存访问和中间 attention 矩阵存储。

维护建议¶

每次更新手册时，建议检查：

  • MCP latest spec 是否仍指向当前版本。
  • A2A latest spec 是否有破坏性变更。
  • OpenAI Agents SDK、LangChain、LlamaIndex、Microsoft Agent Framework 的 API 是否更新。
  • 示例代码是否仍能运行。
  • 参考资料是否仍是官方页面或论文。
